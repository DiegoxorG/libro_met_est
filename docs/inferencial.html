2.1 Unidad de análisis: tabla por paciente

Las pruebas de hipótesis suponen observaciones independientes, y los 5.863 registros no lo son: vienen de 42 pacientes con entre 101 y 168 grabaciones cada uno, que comparten edad y sexo y cuyas puntuaciones motor_UPDRS están interpoladas entre visitas, así que casi no varían dentro de una misma persona. Tratarlos como independientes inflaría el tamaño de muestra y daría p-valores engañosamente pequeños (pseudorreplicación).

Por eso armamos una tabla con un registro por paciente: la severidad motora es el promedio de todas sus grabaciones, y de ahí salen las variables de agrupación: sexo, grupo de edad (menor de 60, 60 a 70 y mayor de 70 años) y nivel de inestabilidad vocal, alto o bajo según el promedio de cada índice quede en la mitad superior o en la mitad inferior de los pacientes. Para comparar el inicio y el final del seguimiento guardamos la primera y la última grabación de cada paciente.

Para no repetir código, definimos dos funciones: el resumen descriptivo por grupo y las tres pruebas de normalidad (Shapiro-Wilk, Kolmogorov-Smirnov sobre datos estandarizados y Lilliefors). Además, para presentar los resultados de las pruebas como tablas en lugar de la salida de la consola, definimos tabla_pruebas, que resume cada prueba (estadístico, grados de libertad, p-valor, estimación e intervalo de confianza del 95 %), y tabla_cohen, que resume la d de Cohen con su intervalo y su magnitud.

resumen_grupo <- function(datos, grupo, variable = "motor") {
  datos %>%
    group_by(.data[[grupo]]) %>%
    summarise(
      n = n(),
      promedio = mean(.data[[variable]]),
      ds = sd(.data[[variable]]),
      mediana = median(.data[[variable]]),
      RIC = IQR(.data[[variable]]),
      Q1 = quantile(.data[[variable]], 0.25),
      Q3 = quantile(.data[[variable]], 0.75),
      min = min(.data[[variable]]),
      max = max(.data[[variable]])
    ) %>%
    mutate(across(where(is.numeric), ~ round(.x, 3))) %>%
    as.data.frame()
}

normalidad_grupo <- function(datos, grupo, variable = "motor") {
  datos %>%
    group_by(.data[[grupo]]) %>%
    summarise(
      n = n(),
      est_w = shapiro.test(.data[[variable]])$statistic,
      p_sw = shapiro.test(.data[[variable]])$p.value,
      est_ks = ks.test(scale(.data[[variable]]), "pnorm")$statistic,
      p_ks = ks.test(scale(.data[[variable]]), "pnorm")$p.value,
      est_l = lillie.test(.data[[variable]])$statistic,
      p_l = lillie.test(.data[[variable]])$p.value
    ) %>%
    mutate(across(where(is.numeric), ~ round(.x, 3))) %>%
    as.data.frame()
}

intervalo <- function(inferior, superior, digitos = 3) {
  paste0("[", round(inferior, digitos), ", ", round(superior, digitos), "]")
}

fila_prueba <- function(x, digitos = 3) {
  # leveneTest devuelve una tabla de ANOVA en lugar de un objeto htest
  if (inherits(x, "anova")) {
    return(tibble(estadistico = paste0("F = ", round(x[["F value"]][1], digitos)),
                  gl = paste(x$Df, collapse = " y "),
                  p_valor = formato_p(x[["Pr(>F)"]][1], digitos),
                  estimacion = "", ic_95 = ""))
  }
  nombre <- dplyr::recode(names(x$statistic),
                   "Bartlett's K-squared" = "K²",
                   "Kruskal-Wallis chi-squared" = "χ²",
                   "X-squared" = "χ²")
  estimacion <- x$estimate
  # en la t de dos muestras se reporta la diferencia de medias
  if (length(estimacion) == 2) estimacion <- estimacion[1] - estimacion[2]
  tibble(
    estadistico = paste0(nombre, " = ", round(x$statistic, digitos)),
    gl = if (is.null(x$parameter)) "" else paste(round(x$parameter, 2), collapse = " y "),
    p_valor = formato_p(x$p.value, digitos),
    estimacion = if (is.null(estimacion)) "" else as.character(round(estimacion, digitos)),
    ic_95 = if (is.null(x$conf.int)) "" else intervalo(x$conf.int[1], x$conf.int[2], digitos)
  )
}

tabla_pruebas <- function(pruebas, titulo, etiqueta = NULL, digitos = 3) {
  map_dfr(pruebas, fila_prueba, digitos = digitos, .id = "prueba") %>%
    tabla(titulo, etiqueta = etiqueta,
          col.names = c("Prueba", "Estadístico", "Grados de libertad", "p-valor",
                        "Estimación", "IC 95 %"))
}

tabla_cohen <- function(efectos, titulo, etiqueta = NULL) {
  magnitudes <- c(negligible = "despreciable", small = "pequeño",
                  medium = "medio", large = "grande")
  map_dfr(efectos, function(x) {
    tibble(d = round(x$estimate, 3),
           ic_95 = intervalo(x$conf.int[1], x$conf.int[2]),
           magnitud = magnitudes[[as.character(x$magnitude)]])
  }, .id = "comparacion") %>%
    tabla(titulo, etiqueta = etiqueta,
          col.names = c("Comparación", "d de Cohen", "IC 95 %", "Magnitud"))
}

2.2.5 Tamaño del efecto

Para interpretar la d de Cohen usamos la escala de referencia: un valor absoluto menor de 0.2 es un efecto despreciable (trivial), de 0.2 a 0.5 pequeño, de 0.5 a 0.8 medio y de 0.8 o más grande. Es la misma escala que usamos en el resto del capítulo.

La Tabla 2.44 reúne todas las pruebas. Solo la comparación entre el inicio y el final del seguimiento resulta significativa: la severidad motora sube en promedio 2.08 puntos (desviación estándar de 6.23) en seis meses, con un efecto pequeño. El sexo y el shimmer no se asocian con la severidad ni estadística ni prácticamente. Los otros dos resultados muestran la diferencia entre significancia y relevancia: el grupo de edad (d = 0.96 entre los grupos extremos, casi 7 puntos) y el jitter (d = 0.44, 3.4 puntos) tienen efectos apreciables que con 42 pacientes no cruzan el umbral del 5 % en las pruebas paramétricas, aunque en el caso de la edad la no paramétrica sí lo hace por poco. Las pruebas de correlación apuntan en la misma dirección: la edad alcanza una correlación débil, significativa con Spearman y marginal con Pearson (r = 0.3); entre las medidas acústicas solo NHR resulta significativa, y únicamente con Spearman (ρ = 0.32), mientras que las demás quedan en correlaciones débiles o muy débiles. El chi-cuadrado cuenta la misma historia en versión categórica: la proporción de pacientes con severidad alta casi se duplica entre los menores de 60 y los mayores de 70 (V de Cramer = 0.27), sin alcanzar la significancia (χ²(2) = 3.13, p-valor = 0.209), y el sexo no se asocia con el nivel de severidad (V = 0). En conjunto, la edad y el paso del tiempo son lo que más claramente se vincula con la severidad motora; la voz, tal como la analizamos aquí, guarda con ella una relación débil.
